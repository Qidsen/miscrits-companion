# Miscrits Companion — Plan 4: Instant, visual Telegram bot on Cloudflare Workers

**Goal:** Move the bot from GitHub Actions polling (15 min) to a Cloudflare Worker webhook (instant replies, digest exactly at 03:00 Kyiv) and make messages visual: a daily card image, sprite albums, inline buttons, and an owner-only `/admin`.

**Spec:** design spec §13.1, amended here: bot hosted on Cloudflare Workers (free plan); site stays on GitHub Pages; GitHub Actions keeps syncing data.

## Constraints
- Cloudflare free plan: 10 ms CPU per invocation → the Worker never parses the 1.2 MB `miscrits.json`; it reads a compact `public/data/bot.json` (built by sync) and caches it in memory.
- KV free plan: 1000 writes/day → state is one KV key (`state`) written only when it changes.
- Webhook requests verified with `X-Telegram-Bot-Api-Secret-Token` (random secret stored as a Worker secret).
- Images: weekday cards are pre-rendered by sync with `sharp` (7 PNGs, `public/data/cards/<day>.png`, 1200×630) — the Worker only sends their URLs. Personal lists use `sendMediaGroup` with CDN sprite URLs (≤10).
- Existing subscribers are migrated from `notify/state.enc` by a one-off GitHub workflow (it has `NOTIFY_KEY`) posting to the Worker's `/admin/import` guarded by `ADMIN_TOKEN`.
- Owner for `/admin`: set by `/claim <ADMIN_TOKEN>` once (stored in state).
- `notify.yml` is removed after migration.

## Tasks
1. **Sync: bot data + weekday cards.** `scripts/sync/botData.ts` (`buildBotData(snapshot) → { v, miscrits: [{id,n,r,e,s:[region,zone,days|'all'][]}], zones }`), `scripts/sync/cards.ts` (`cardLayout(miscrits, day)` pure: which miscrits and positions; renderer with sharp: dark gradient background, title "Игровой день: <day>", up to 8 rare sprites with rarity rings + names). Tests: compact data round-trips spawns; layout picks exclusive Exotic/Legendary first, max 8, deterministic.
2. **Bot core refactor.** `digest`/`commands` take `BotData` (compact); replies become `{ chatId, text, buttons?, photo?, album? }`; add `/admin` (owner only: subscriber count + names, groups), `/claim`; personal digest attaches the album of hunted miscrits available today; daily messages attach the weekday card + buttons (Map, Hunt, Site). Tests updated/added.
3. **Worker.** `bot/worker.ts`: `fetch` (POST `/tg` with secret header → applyUpdate → send; POST `/admin/import`; GET `/health`), `scheduled` (cron every 15 min at minute 0/15… → sends daily once per game date, resumable via `sent`), KV state, cached `bot.json` fetch from Pages. `wrangler.toml` with KV binding and cron. Telegram client gains `sendPhoto`, `sendMediaGroup`, `reply_markup`.
4. **Deploy + migrate.** `npm run bot:deploy` (wrangler deploy), secrets (`TELEGRAM_TOKEN` by the owner via `wrangler secret put`, `WEBHOOK_SECRET`, `ADMIN_TOKEN` generated), `scripts/bot/setWebhook.ts`, `.github/workflows/migrate-bot.yml` (manual) → import; delete `notify.yml` and `scripts/notify/index.ts`; docs update.
5. **Verify + review.** Unit tests, a live `/health` check, `getWebhookInfo` shows no errors, `/today` answered within seconds; fresh review.
